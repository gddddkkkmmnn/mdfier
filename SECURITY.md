# Security policy

mdfier handles page text and user-pasted content locally. Do not include private page captures, account identifiers, session URLs, or clipboard contents in an issue or pull request.

For a suspected security issue, use GitHub's **Report a vulnerability** action for this repository if private vulnerability reporting is enabled. Include the affected version, browser, steps to reproduce, and impact. Do not post exploit details in a public issue. If private reporting is unavailable, open an issue asking the maintainers for a private contact route without including the vulnerability details.

Supported release: the latest AMO-listed version once publication begins. Before the first AMO release, report against the current `main` build.
