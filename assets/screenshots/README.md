# Product screenshots

Genuine screenshots of mdfier 0.4.2 installed in isolated browser profiles, using the anonymous local documentation fixture. No personal browsing data or generated interface mockups.

- Firefox: Preview, Markdown and empty state at 1280 × 800, captured with `scripts/verify-firefox.py`.
- Chrome: native Chrome for Testing window, Preview and Markdown. The actual Retina captures were exported as PNG at 1280 × 800 without replacing or drawing any interface elements. The testing-browser notice remains visible.

These files are suitable for listing preparation; screenshots are independent of the promotional artwork in `assets/store/`.
