# Brand assets

- `mdfier-github-avatar.png` is the approved square extension mark at 128×128. GitHub repositories do not have a separate per-repository avatar; changing the maintainer's profile picture would affect all of their repositories.
- `github-social-preview.png` is the 1280×640 repository preview image. To display it on GitHub, open **Settings → General → Social preview** and upload this file after confirming the repository is ready to be public. The SVG beside it is the editable source.
- `brand/mdfier-mark.png` and `brand/mdfier-wordmark.png` are the supplied high-resolution brand originals. They are not shipped in the extension package.
