# Changelog

## 0.4.3 — unreleased patch

- Preserve authored comments, related sections and profiles that contain reply controls; remove only control-only regions.
- Replace stale capture handlers in already-open tabs after updating the extension.

Automated checks and remaining browser acceptance are recorded in [patch notes](docs/patch-0.4.3.md).

## 0.4.2 — initial MVP release

- Local Page, Block, Selection and Paste capture to Markdown.
- Shared Firefox/Chrome sidebar with editing, safe preview, copy and download.
- Toolbar access in both browsers and a selection context-menu action.
- Independent drafts for open tabs and one-click Clear.
- English/Ukrainian interfaces, system light/dark themes and narrow-panel support.
- Conservative extraction with local Mozilla Readability and Turndown/GFM.
- Accessible native text editor and keyboard-focusable preview.
- Repeatable production packages, reviewer source archive and SHA-256 checksums.

Published on Firefox Add-ons and Chrome Web Store. See [verification](docs/verification.md) for release acceptance and public installation links.
